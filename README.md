# 🧊 沉浸式 LLM 交互前端

> 一个仿微信设计风格、基于 Kotlin 构建的 Android 端大语言模型交互客户端。

本项目是 **“Vibe Coding”** 的产物，很多代码由 AI 辅助生成，因此存在不少意料之外的 Bug。但我会持续关注 Issues，和大家一起把它打磨得更好！欢迎体验、反馈和 PR。

---

## 📱 界面与功能

目前已完成四个核心主界面的基本交互框架：

- **💬 聊天（Chat）**：与智能体进行对话，支持长对话自动切分，模拟真人对话时的停顿与节奏感。
- **👥 联系人（Contacts）**：管理你的智能体好友，支持为每个联系人单独设置**智能体配置**、**头像**和**聊天背景**。
- **🌐 朋友圈（Moments）**：智能体可以主动发动态，模型具备调用工具的能力，让 AI 不再局限于对话框。
- **👤 我的（Profile）**：管理应用设置，目前支持**添加 LLM 供应商**（如 OpenAI、Anthropic 或本地模型端点）。

### 🧠 进阶能力

- **工具调用**：模型可以调用工具来发布朋友圈，实现真正的“AI 社交”。
- **记忆系统**：智能体会记录对话中的关键信息，形成长期记忆。
- **群组聊天**：支持组建群聊，让多个智能体或人机共同参与对话。

## 🛠 技术栈

- **语言**：Kotlin
- **框架**：Android Native（XML + Jetpack 组件）
- **网络**：Retrofit / OkHttp
- **数据存储**：Room / DataStore
- **架构**：MVVM（部分模块）+ 传统 MVC（遗留部分）

## 📦 如何获取与使用

EchoChat 是一个完整的 Android 应用，开箱即用。

1. **下载安装包**
   - 前往 [Releases](https://github.com/tea-whale/EchoChat/releases) 页面下载最新版本的 APK 安装包。
   - 将 APK 传输至 Android 手机并安装（安装时可能需要开启“允许未知来源应用”权限）。

2. **配置 LLM 供应商（可选）**
   - 请申请自己的 LLM API Key（如 OpenAI、DeepSeek 等），在 App 内的“我的” -> “供应商管理”中添加。


> 💡 **给开发者**：如果你想自行编译或二次开发，请克隆仓库后在 Android Studio 中打开，等待 Gradle 同步完成后即可运行。API Key 相关配置请参考项目内的代码注释。
